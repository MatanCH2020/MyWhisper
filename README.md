## ⚡ התקנה בפקודה אחת

פתח PowerShell והדבק:

```powershell
irm https://raw.githubusercontent.com/MatanCH2020/MyWhisper/main/scripts/install.ps1 | iex
```

הפקודה מתקינה Git ו-Python 3.12 אם חסרים, מורידה את הפרויקט ל-`%USERPROFILE%\MyWhisper`,
מתקינה את כל התלויות (כולל ספריות CUDA), שמה קיצור **MyWhisper** על שולחן העבודה,
**ופותחת את האפליקציה מיד**. הרצה חוזרת מעדכנת לגרסה האחרונה שפורסמה, לאחר סגירת האפליקציה.
אפשר לעדכן גם דרך ההגדרות: הבדיקות המקדימות רצות לפני הסגירה האוטומטית.

> בהרצה הראשונה יורד מודל התמלול (‎~1.5–3GB) — פעם אחת בלבד.

### 🗑️ הסרה מלאה

רוצה להסיר את התוכנה? פתח PowerShell והדבק:

```powershell
irm https://raw.githubusercontent.com/MatanCH2020/MyWhisper/main/scripts/uninstall.ps1 | iex
```
הפקודה סוגרת את התוכנה, מוחקת את קיצורי הדרך ואת כל תיקיית ההתקנה מהמחשב.
אם חיברתם חשבון ChatGPT, בחרו **ניתוק** בהגדרות לפני ההסרה. אפשר לבטל את ההרשאה
גם ב-[הגדרות השימוש של ChatGPT](https://chatgpt.com/settings/usage).
קובץ רישום החשבונות המוצפן בתיקיית המשתמש נמצא מחוץ להתקנה ונשמר לחיבור חוזר;
ניתוק מסיר ממנו את האסימונים, אך משאיר את מזהי הרישום.

## 🎬 איך משתמשים

| מקש | פעולה |
|---|---|
| `Ctrl+Space` | התחלת הקלטה 🔴 (ביפ + מחוון בראש המסך) |
| `Ctrl+Space` שוב | עצירה → תמלול 🟡 → הטקסט מודבק לשדה הפעיל |
| `Esc` בזמן הקלטה | ביטול — ההקלטה נזרקת בלי תמלול |
| `X` על החלון | מזעור למגש — התוכנה ממשיכה להאזין ברקע |

יציאה מלאה: חץ למעלה ליד השעון ← קליק ימני על אייקון המיקרופון ← **יציאה**.
הקלטה שנשכחה פתוחה נעצרת ומתומללת אוטומטית אחרי 10 דקות.

חיווי ההקלטה מופיע למעלה במרכז **המסך שבו נמצא העכבר בתחילת ההקלטה**,
בחלונית קומפקטית עם מיקרופון, זמן הקלטה נפרד, גלי קול ורמז Esc לביטול.
הוא נשאר באותו מסך ובאותו גודל גם בזמן התמלול,
בלי לקחת את הפוקוס משדה ההקלדה. בכל הקלטה חדשה המסך נבחר מחדש.
אנימציית הכניסה מכבדת את הגדרת האנימציות של Windows.

## 🧠 התוכנה לומדת אותך

כל תמלול נשמר בלשונית **היסטוריה**. מילים שהמערכת לא מכירה (בעיקר מונחים לועזיים
שוויספר משבש) מסומנות **באדום** — לוחצים על המילה ובוחרים:

- **"שמור תיקון"** — מקלידים את הצורה הנכונה (מילה לועזית? באנגלית: `render`, `thumbnail`).
  מעכשיו התיקון חל אוטומטית על כל תמלול, והמודל מכוון להפיק אותה נכון מלכתחילה.
- **"המילה תקינה"** — נכנסת למילון האישי ולא תסומן שוב.

לשונית **מילון** מרכזת את כל מה שנלמד ומאפשרת למחוק תיקון.

## 📋 תמלולים, העתקות ותמונות במקום אחד

לחצו על ‎``Ctrl+` ``‎ לפתיחת החלון, או בחרו **העתקות** בניווט הראשי (Ctrl+4) ובתפריט המגש. כל תמלול נשמר כאן לפני ההדבקה, גם אם ההדבקה לא הצליחה.
גם התמלולים הקיימים מיובאים פעם אחת, לפי תאריך וללא כפילויות.
השהיית המעקב עוצרת העתקות חיצוניות בלבד; תמלולים ממשיכים להישמר.
מחיקה כאן אינה מוחקת מהיסטוריית התמלולים. קליק על פריט מציג את כל הטקסט באזור נגלל,
או תמונה גדולה עם כפתורי הגדלה, הקטנה, גודל מקורי **100%** והתאמה לחלון.
הרשימה מימין מציגה את התוכן בלבד; רוב השטח משמאל מוקדש לתצוגה המלאה.
כפתור **הרחב** מפנה שטח נוסף לתוכן. אפשר לגרור את המחיצה כדי להתאים את החלוקה.
**העתק ללוח וסגור**, Enter מתוך הרשימה/החיפוש או לחיצה כפולה מעתיקים את הפריט ללוח;
לאחר מכן מדביקים אותו בשדה הרצוי עם Ctrl+V.
ניתן לגרור את הכותרת, לשנות גודל מהקצוות או מהידית, ולהגדיל למסך מלא.
כפתור X סוגר את החלון. Esc חוזר מתצוגה מורחבת לרשימה; במצב הרגיל הוא סוגר.
קיצור המקשים מחזיר חלון מכוסה או ממוזער לחזית ושומר את החיפוש, הבחירה והגלילה.
כשהחלון כבר פעיל, הקיצור סוגר אותו. אם Windows מסרב להעביר מיקוד, החלון מהבהב בסרגל המשימות.
ניקוי כל ההעתקות דורש אישור.

המסננים **הכול / תמונות / טקסט / קישורים / מועדפים** מאפשרים להגיע לתוכן בלחיצה.
במסנן תמונות נפתחת גלריה, ואפשר לעבור לרשימה. בחירת מסנן מנקה חיפוש קודם.
חיפוש תמונות עובד לפי שם ותאריך; אין זיהוי טקסט מתוך תמונה (OCR).
השורות מציגות רק טקסט או תמונה, ללא תאריך ושעה; התאריכים נשמרים לצורך מיון וחיפוש.
היסטוריה ארוכה נטענת ב־100 פריטים בכל פעם עם „הצג עוד”.
אפשר להוסיף למועדפים, למחוק פריט ולבטל את המחיקה האחרונה כל עוד האפליקציה פתוחה.
כפתור ההשהיה וחיווי המעקב נמצאים גם בחלון ההעתקות. כשל בהעתקה משאיר את החלון פתוח.
בחלון נמוך הפעולות המשניות ומצב השמירה זמינים בתפריט **⋯**, כדי להשאיר יותר מקום לתוכן.

צילומי מסך עם `CanIncludeInClipboardHistory=1` נשמרים; ערך 0, ערך לא תקין או סימון
סודיות מפורש נחסמים. איסור סנכרון לענן לבדו אינו אוסר היסטוריה מקומית.
בהעתקה שכוללת תמונה וטקסט נשמרת התמונה. קובצי PNG/JPEG/WebP/BMP/GIF מקומיים
נקלטים כתמונה (ב־GIF הפריים הראשון); אין הורדת תמונות מקישורים או מתיקיות רשת.
יבוא קובץ מוגבל ל־40 מיליון פיקסלים. העתקת תמונה זהה מעדכנת את מיקומה בלי לשכפל.
נשמרות עד 30 תמונות שאינן מועדפות, בנוסף למועדפים; יש להסיר מועדפים או למחוק ידנית
כדי לפנות את האחסון שלהם. צילומים שנחסמו בעבר אינם משוחזרים אוטומטית.

<img src="docs/app-clipboard-dark.png?v=1.15.1" width="900" alt="רשימת העתקות נקייה עם תמונות גדולות ותצוגה מלאה">

המעבר בין בהיר לכהה מתבצע בתוך החלון הקיים. גם החלון הראשי ניתן להגדלה
באמצעות הכפתור בכותרת או גרירת הקצוות. עיבוד מודלי שפה באמצעות Ollama הוסר בגרסה 1.12.0.

## ✍️ שיפור הטקסט עם ChatGPT — תוספת לבחירה

התמלול המקומי עובד גם בלי חשבון או אינטרנט. התוספת **כבויה בהתקנה חדשה וגם בשדרוג**.
להפעלתה פתחו **הגדרות ← שיפור הטקסט עם ChatGPT**:

1. בחרו **דפדפן להתחברות** שבו כבר נכנסתם לחשבון (למשל Google Chrome), לחצו **Continue with ChatGPT** והשלימו אישור בדפדפן החיצוני שנבחר. כל משתמש מחבר את חשבונו האישי. MyWhisper אינו קורא את עוגיות הדפדפן או הסיסמאות.
2. בחרו מודל מהקטלוג של החשבון. **GPT-6 Luna** נבחר אם זמין, עם `reasoning.effort=none`; אחרת יש לבחור מודל. התחברות אינה מפעילה עריכה.
   בראש הכרטיס מופיע **מצב החיבור לחשבון** עם החשבון הפעיל. **מצב עריכת הטקסט** מופיע בנפרד: גם כשמחוברים, העריכה נשארת כבויה עד להפעלה מפורשת. בזמן התחברות יופיע „ממתין לאישור בדפדפן”; אם האישור לא התקבל, ההסבר נשאר בכרטיס גם אחרי שההודעה הזמנית נעלמת.
   דף החזרה בדפדפן מציג הצלחה רק לאחר אימות הזהות ושמירת ההרשאות. אם מוצג בו כשל, החיבור טרם הושלם; חזרו לכרטיס ההגדרות ופתחו ניסיון חדש. אין צורך להפעיל עריכה כדי להתחבר.
3. הפעילו **הפעל עריכה בענן** ואשרו: **טקסט ההכתבה יישלח ל־OpenAI לעריכה. האודיו והתמלול נשארים במחשב. השימוש כפוף לזכאות ולמכסת החשבון.** כלומר רק עותק הטקסט נשלח לעריכה; התמלול המקורי והאודיו מעובדים מקומית.
4. להחזרת מסלול מקומי בלבד, כבו את המתג. הכיבוי מפסיק עריכות וחידוש הרשאות ברקע מיד. „ניתוק” מוחק את ההרשאות המקומיות ומנסה לבטל גם את ההרשאה בשרת.

העריכה מנקה חזרות מקריות והיסוסים ומשפרת פיסוק וניסוח, תוך הנחיה לשמירת המשמעות,
השמות, המספרים, השלילה, האנגלית והחזרות המכוונות. היא אינה מבטיחה תיקון של כל טעות בזיהוי.
המסלול הוא **תמלול מקומי → מילון תיקונים → עריכת טקסט → הדבקה אחת**.
בכשל הרשאה, מכסה או חריגה מתקציב כולל של **שתי שניות נוספות**, משתמשים בתמלול המקומי,
מציגים חיווי קצר ומתעלמים מפלט חלקי או מאוחר. מהירות ואיכות בפועל תלויות בחשבון, ברשת ובמודל;
תקציב הזמן הוא גבול המתנה, ולא הבטחה שהעריכה תושלם.

בהיסטוריה אפשר לבחור **הצג מקור** כדי לראות את התמלול לאחר המילון ולפני OpenAI.
מעבר לחלון אחר בזמן העיבוד שומר את התוצאה בהיסטוריה ומציג הודעה, במקום להדביק בחלון האחר.
הרשאות OAuth נשמרות מוצפנות ב-Windows DPAPI, עבור משתמש Windows הנוכחי בלבד, ב-
`%LOCALAPPDATA%\MatanDigital\MyWhisper\chatgpt.dpapi`. הן אינן נשמרות בפרויקט או במתקין.
חשבון שאינו זכאי ממשיך בתמלול מקומי; **אין מעבר אוטומטי ל-API בתשלום**.
[ניהול שימוש והרשאות ב-ChatGPT](https://chatgpt.com/settings/usage) מאפשר לבדוק מכסה וניתוק.
בקשות העריכה משתמשות ב-Responses API עם `store=false` ו-`stream=true`; רק תשובה שהושלמה מתקבלת.

### הכתבה עם עברית ואנגלית

אפשר לשלב מונחים באנגלית בתוך משפט בעברית, למשל „אני רוצה לבנות אפליקציה ל־iOS ול־Android”.
בעמוד **מילון** אפשר להוסיף שמות מוצרים ומונחים באנגלית; מונחים שנוספו לאחרונה מקבלים
עדיפות בהכוונת התמלול. ההכוונה מוגבלת ואינה מוזנת פעמיים, כדי למנוע עומס שגרם להשמטת
מילים בהכתבות משולבות. זהו חלק מהתמלול המקומי ופועל גם כשהתוספת של ChatGPT כבויה.
המילון עוזר לזיהוי, אך אינו מבטיח לזהות כל מילה או לכתוב כל מונח לועזי באנגלית.

### תיקון חכם של ההיסטוריה ולמידה להמשך

בעמוד **מילון** לחצו **סרוק ותקן את ההיסטוריה**, לאחר חיבור חשבון, בחירת מודל והפעלת
עריכת טקסט בהגדרות. הפעולה שולחת את היסטוריית **התמלולים** השמורה ל-OpenAI לפי
המשפט המלא, לתיקון כתיב ותחביר ולכתיבת מונחים לועזיים באנגלית, למשל „גיטהאב” → `GitHub`.
האודיו והיסטוריית ההעתקות אינם נשלחים. הפעולה משתמשת במכסת החשבון האישי.

אם חסרה הגדרה, מופיע הסבר וכפתור **פתח הגדרות להפעלת הסריקה** מוביל להגדרות ChatGPT.
המעבר אינו מפעיל עריכה או מתחיל סריקה. **הצג תוצאות** וביטול תיקונים שמורים זמינים
גם כשהעריכה בענן כבויה; הם אינם דורשים התחברות מחדש.

הסריקה ידנית ואינה מתבצעת בהפעלה או ברקע ללא לחיצה. מחוון התקדמות וכפתור ביטול
מאפשרים להמשיך לעבוד; כל קבוצה מוגבלת ל-45 שניות, בנפרד מתקציב שתי השניות להכתבה.
בזמן הסריקה מוצגים השלב, הקבוצה הנבדקת, מספר התמלולים שנבדקו, הזמן שחלף וזמן ההמתנה.
התיקונים נשמרים רק בסיום תקין של כל הסריקה. בכיבוי התוספת, ניתוק או החלפת חשבון
הסריקה נעצרת ללא החלת תשובה מאוחרת. רשומות שנערכו או נמחקו במהלך הסריקה אינן נדרסות.

תיקון ברור ועקבי למילה שאינה מוכרת נלמד במילון אם כל הופעותיה בסריקה תוקנו באותה
דרך. כללים ידניים קיימים נשמרים. תיקון שתלוי בתחביר או בהקשר מתקן את המשפט בהיסטוריה
ואינו הופך להחלפה קבועה. מונחים באנגלית מתווספים למילון המונחים כדי לעזור לתמלול הבא.
המודל אינו מבטיח לזהות כל טעות; הצעה שלא ניתן להתאים למקור, או שמשנה מספר או שלילה,
נדחית בנפרד ואינה מבטלת תיקונים אחרים שאומתו. תיקונים חופפים נדחים שניהם.

בסיום מוצג סיכום קבוע: כמה תמלולים תוקנו, כמה תיקונים נלמדו, כמה מונחים באנגלית נוספו
וכמה הצעות נדחו ומדוע. **הצג תוצאות** פותח טבלת **לפני / אחרי**, סוג התיקון והאם נלמד
כלל חדש להכתבות הבאות. גם סריקה ללא שינויים, ביטול או כשל מקבלים הסבר ברור.
הסיכום נשמר ב-`history_scan_report.json` הפרטי ונשאר גלוי גם אחרי הפעלה מחדש;
הוא עשוי לכלול מילים מתמלולים, ולכן אינו נכלל ב-Git או במתקין.

**הצג מקור** שומר גישה למקור. **בטל את התיקונים שנשמרו** משחזר גם לאחר
הפעלה מחדש ומסיר רק תוספות של הסריקה שלא נערכו מאז. גיבוי הביטול האישי נשמר ב-
`history_scan_undo.json`, לצד ההיסטוריה, ואינו נכלל ב-Git או במתקין. סריקה מוצלחת נוספת
מחליפה את גיבוי הביטול; היא אינה מוחקת את המקור שכבר נשמר ברשומות.

## יציבות, גיבוי ובדיקות למפתחים

- התקנה ועדכון בוחרים תג גרסה שפורסם ב-GitHub. עדכון נעצר אם יש שינויי קוד מקומיים, כולל קבצים שטרם נוספו ל-Git. אין איפוס כוחני של התיקייה.
- לפני החלפת גרסה נשמרים ארכיון קוד ועותק של סביבת Python תחת `.update-backups`. כשל בהתקנה או בבדיקת ההפעלה מחזיר את הגרסה הקודמת ואת הסביבה. הגיבויים נשמרים גם אחרי הצלחה; יש לפנות מקום של כשני עותקי הסביבה ועוד 2GB. אחרי אימות הגרסה אפשר למחוק גיבויים ישנים באופן ידני.
- כשל כתיבה מוצג בהודעה. קובץ JSON פגום מגובה בקובץ `*.corrupt-*.bak` לפני התאוששות. הגיבויים מכילים מידע אישי ונשארים מקומיים; הם מוחרגים מ-Git.
- שחזור הלוח מתבצע רק אם תוכנו לא השתנה מאז ההדבקה. נתמכים טקסט, DIB/DIBV5, רשימות קבצים, HTML, RTF, PNG וסימוני מנהלי סיסמאות. פורמטים פרטיים אחרים של יישומים אינם משוחזרים. תמונת מצב מעל 64MB לא תוחלף; התמלול נשאר בהיסטוריה.
- תוכן התמלול אינו נכתב ללוג. ההיסטוריה והמילונים נשמרים מקומית כרגיל.
- עמודי הממשק נמצאים ב-`app/ui_pages`; `app/ui.py` נשאר מעטפת הבקר, החלון והרכיבים המשותפים. הממשק ממשיך לקבל את פעולות המנוע באמצעות callbacks.
- קובצי `requirements*.in` מתארים תלויות ישירות; `requirements*.txt` נועלים את התלויות הישירות והעקיפות שנבדקו ב-Windows x64 ו-Python 3.12. עדכון שלהן דורש בדיקת התקנה נקייה ובדיקת GPU לפני הפצה.

```powershell
.\.venv\Scripts\python -m unittest discover tests
.\.venv\Scripts\python -m pip check
.\.venv\Scripts\python scripts\verify_install.py
```

הבדיקה האחרונה טוענת את המודולים ואת Qt ללא הקלטה, רישום קיצורי מקלדת או הורדת מודל. CI מריץ התקנה נקייה ובדיקות על Windows עם Python 3.12; הוא אינו מאמת תמלול על GPU.

לפני פרסום גרסה: לבדוק הכתבה אמיתית בעברית ובשילוב אנגלית על GPU ועל CPU, הדבקה ב-Notepad ובדפדפן, ניתוק וחיבור מיקרופון, Esc, עצירה אוטומטית, לחיצות מהירות, מסך מלא ועבודה ללא רשת כשהמודל כבר נמצא במטמון. יש לוודא שמספר הגרסה, השינויים ותג ה-GitHub תואמים.

### מצב משחק / מסך מלא

כשהחלון הפעיל מכסה מסך שלם, MyWhisper משהה את ההקלטה אוטומטית תוך כשנייה: קיצור ההקלטה משתחרר והמודל מפנה את הזיכרון. לחיצה על הקיצור בזמן מסך מלא אינה פותחת את מחוון ההקלטה. ביציאה הקיצור חוזר ללא טעינה מוקדמת של המודל. גם משחק ללא שוליים ווידאו במסך מלא מפעילים את ההשהיה; חלון רגיל שמוגדל לאזור העבודה אינו אמור להפעילה.

קיצור התמלולים וההעתקות ומעקב הלוח נשארים פעילים. הקלטה שכבר החלה נעצרת ונשמרת כתמלול ברקע, ללא הדבקה; תמלול פעיל מסתיים לפני שחרור המודל. ניתן לבטל התנהגות זו באמצעות `release_on_fullscreen=false` ב־`config.json`. אם תוכנה אחרת תפסה את הקיצור בזמן ההשהיה תופיע הודעה ביציאה, ויש לבחור קיצור אחר בהגדרות.
