# אימות השהיה במסך מלא — 1.13.4

נבדק ב־17 באוקטובר 2026 על Windows עם RTX 4070 Ti SUPER, Python 3.12
והמודל המקומי `ivrit-ai/whisper-large-v3-ct2` ב־CUDA/float16.

## התנהגות

`release_on_fullscreen=true` מפעיל השהיה של קיצור ההקלטה ושחרור מודל.
הסנכרון מתבצע מדי שנייה ולפני כל ניסיון הקלטה/טעינה. ביציאה נרשם מחדש
הקיצור שנבחר, והמודל נשאר משוחרר עד לשימוש הבא. מעקב ההעתקות והקיצור שלו
ממשיכים לפעול. הקלטה פעילה נעצרת ומתומללת ברקע עם יעד חסום להדבקה;
תמלול או טעינה פעילים מסתיימים לפני שחרור המודל.

## בדיקת Windows ו־GPU

`scripts/check_fullscreen_pause.py --auto --geometry-only` הציג חלון Qt אמיתי
בגודל המסך הראשי, 3440×1440, ואז החזיר אותו לגודל רגיל. נבדקו בפועל
`GetWindowRect`, `MonitorFromWindow`, `GetMonitorInfoW`, רישום ושחרור קיצור
Windows ומודל CUDA. החלפת החלון הפעיל במצב בדיקה זה מבוקרת: רק
`GetForegroundWindow` הוחלף להחזיר את ידית חלון הבדיקה. זהו אינו ניסוי בתוך משחק.

- בכניסה למסך מלא הקיצור הוסר; רישום אותו צירוף בידי בעלים אחר הצליח.
- המודל שוחרר: צריכת GPU כוללת ירדה מ־14532MiB ל־10776MiB, הפרש 3756MiB.
  המדידה כוללת פעילות אחרת במחשב ואינה מדידת זיכרון מבודדת של המודל.
- קריאת toggle בתור בזמן ההשהיה לא הפעילה הקלטה או טעינת מודל.
- ביציאה הקיצור חזר ללא טעינת מודל. ניסיון רישום מתחרה נכשל כמצופה.
- כאשר בעלים אחר החזיק בקיצור בזמן היציאה, הוצגה הודעה אחת ללא קריסה או טעינה.

הניסיון הראשוני לבדוק גם מיקוד אמיתי נכשל משום ש־Windows לא העניק לחלון
שהופעל ברקע זכויות foreground. הבדיקה זיהתה זאת ועצרה, ולא הוצגה כהצלחה.
בדיקה אינטראקטיבית מלאה זמינה בהרצת הסקריפט בלי הדגלים ולחיצה על הכפתור.

## רגרסיות

בדיקות יחידה מכסות מסך מלא עם מודל משוחרר, כניסה בזמן טעינה/תמלול/הקלטה,
שמירת טקסט ללא הדבקה או הודעה קופצת, עדכון הקיצור בזמן השהיה, כשל רישום
ביציאה, ביטול האפשרות, ידיות חלון 64-bit, מסך עם קואורדינטות שליליות,
חלון רגיל מוגדל לאזור העבודה והחרגת שולחן העבודה.
